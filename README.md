# Assembly String Reversal

Two implementations of a string reversal algorithm written in assembly: ARM64 and x86-64.

The project was created as a practical exercise in low-level programming, focusing on registers, pointers, memory access, loops, conditional branches, and in-place string manipulation.

## Implementations

* ARM64 (AArch64)
* x86-64

Both implementations reverse a null-terminated string directly in memory without using a high-level language.
